# 家計簿

スマホでもPCでも使える、ブラウザだけで動く家計簿アプリです。データは端末のブラウザ内（localStorage）に保存され、外部サーバーには送信されません。

## 機能

| 画面 | 内容 |
| --- | --- |
| ホーム | 今月の支出総額、自分の買い物／生活費／貸したお金／競馬の内訳、日別グラフ、税金のお知らせ |
| 明細 | 日付順の明細（新しい順・古い順）、分類フィルタ、検索、タップで編集・削除 |
| 集計 | 月ごとの支出グラフ（12か月）、収入と支出、カテゴリ別（月・年） |
| 貸し借り | 誰に・いつ・いくら貸したか／誰から・いつ・いくら返ってきたか、返済履歴、未返済残高。貸した金額は日別支出に含まれます |
| 競馬 | 生活費とは別管理。購入額・払戻額・収支・回収率を月別・年別に表示 |
| 税金 | 副業（雑所得）と競馬（一時所得）から年間の税金を概算。20万円の申告ラインを超えると所得税・住民税の額を表示 |
| 固定費 | 毎月の支払いを登録／解除／再開。支払日になると自動で明細に記入 |
| 設定 | パソコン・スマホの自動同期、アプリのインストール、Gmail取り込み、バックアップ（JSON）・復元、CSV書き出し |

### 入力方法
- **手入力**：右下の「＋」から
- **音声入力**：「昨日スーパーで食費2500円」「田中さんに5000円貸した」「田中さんから3000円返してもらった」「競馬で3000円買って払い戻し1万2000円」「副業の報酬5万円入金」など（Chrome / Safari / Edge）
- **レシート撮影**：撮影した画像から店名・日付・合計金額を読み取り（OCRエンジンと日本語データはアプリに同梱し、端末内で処理）
- **Gmail取り込み**：登録したGmailに届くクレジットカードの利用通知メールから利用日・利用先・金額を読み取り。楽天・三井住友・JCB・イオン・dカード・エポス・PayPay・AMEX・セゾンなどの形式に対応。取り込み済みのメールは重複しません

## アプリとしてインストールする

インストールできるWebアプリ（PWA）になっているので、パソコンではデスクトップアプリ、スマホではホーム画面のアプリとして使えます。オフラインでも起動でき、新しいバージョンは自動で反映されます。アプリ内の「設定 → アプリとしてインストール」にも同じ手順とスマホ用QRコードがあります。

> **更新について**：新しい版を公開すると、アプリを次に開いたときに自動で入れ替わります（再インストールは不要）。
> すぐに反映したいときは、アプリを完全に閉じて開き直すか、「設定 → アプリとしてインストール」の「最新版を確認」を押してください。

### Android スマホ（おすすめ）
1. パソコンの「設定 → アプリとしてインストール」の QR コードをスマホのカメラで読み取り、**Chrome** で開く
2. 「📲 インストール」（または ⋮ →「アプリをインストール」）を押す
3. ホーム画面とアプリ一覧に「家計簿」が追加され、ほかのアプリと同じように起動できます

Android ならではの機能:
- **共有メニューから記録**：ギャラリーのレシート写真や、カード利用通知（Gmail アプリ・LINE・通知の文章など）を「共有」→「家計簿」で送ると、読み取って入力画面が開きます（写真はそのまま文字を読み取り）
- **アイコンの長押し**で「明細を追加」「音声で入力」「レシートを撮影」をすぐ開ける
- **戻るボタン**で入力画面を閉じる → ホームに戻る（いきなりアプリが閉じない）

### Windows パソコン（デスクトップにショートカット）
1. パソコンで公開URLを開き、「設定 → アプリとしてインストール」の **「🖥️ デスクトップにショートカットを作る（Windows）」** を押してファイルを保存
2. 保存した `kakeibo-shortcut.cmd` をダブルクリック（「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」）
3. デスクトップに「家計簿」アイコンができ、アプリ専用のウィンドウで開きます（Chrome があれば Chrome、なければ Edge を使用）

スタートメニューやタスクバーにも入れたい場合は、Chrome / Edge のアドレスバー右端のインストールアイコンからもインストールしてください。

### Mac
1. Chrome / Edge で公開URLを開き「インストール」（Safari はメニュー「ファイル → Dockに追加」）
2. デスクトップに置く場合：Finder の「アプリケーション → Chrome Apps」から家計簿を option+command を押しながらデスクトップへドラッグ

### iPhone / iPad
1. **Safari** で公開URLを開く（パソコンの「設定」画面のQRコードをカメラで読み取ると簡単）
2. 共有ボタン →「ホーム画面に追加」→「追加」


## パソコンとスマホの自動同期

無料の Firebase（Google のクラウドデータベース）を使い、同じアカウントでログインした端末どうしでデータをリアルタイムに同期します。

- 明細・固定費・設定（税金・Gmail取り込みの設定）が同期されます
- オフライン中の変更は端末に保存され、接続したときに自動で送信されます
- 明細は1件ずつ同期するので、別々の端末で別の明細を同時に編集しても消し合いません（同じ明細を同時に編集した場合は後から保存した内容が残ります）
- 初めて接続した端末は、その端末にあったデータとクラウドのデータが合わさります
- データは自分のアカウントでしか読み書きできません（`firestore.rules`）

### 1台目の準備（約5分）
1. [Firebase コンソール](https://console.firebase.google.com/)で「プロジェクトを作成」
2. **Authentication** →「始める」→「メール/パスワード」を有効化（Google ログインも使う場合は「Google」も有効化し、「設定 → 承認済みドメイン」に `akaobaotian-lab.github.io` を追加）
3. **Firestore Database** →「データベースを作成」（本番環境モード、ロケーションは `asia-northeast1` など）
4. Firestore の「ルール」タブに [`firestore.rules`](firestore.rules) の内容を貼り付けて「公開」
5. プロジェクトの設定 →「マイアプリ」でウェブアプリを追加し、表示された `firebaseConfig` をコピー
6. 家計簿アプリの「設定 → 自動同期」に貼り付けて「接続」→「新規登録」

### 2台目以降
- 1台目の「設定 → 他の端末を接続」の QR コードをスマホのカメラで読み取り、同じアカウントでログイン
- **iPhone でホーム画面に追加したアプリ**は Safari とデータが別になるため、「リンクをコピー」→ LINE やメールでスマホに送り、アプリの「設定 → 自動同期」の欄に貼り付けてください

### （おすすめ）接続情報をアプリに組み込む
リポジトリの **Settings → Secrets and variables → Actions → Variables** に `FIREBASE_CONFIG` という名前で `firebaseConfig` の内容（`{ apiKey: ... }` の部分）を登録すると、公開時にアプリへ組み込まれます。どの端末も「ログインするだけ」で同期できるようになります（この情報は公開されても問題のない識別子で、データはログインとルールで保護されます）。

### Gmail取り込みの準備（初回のみ・パソコンで約5分）
Google Cloud の設定は不要です。自分の Google アカウントで小さなスクリプト（Google Apps Script）を動かして、カードの利用通知メールだけを家計簿に渡します。

1. アプリの「設定 → Gmail取り込み → かんたん設定」で「📋 スクリプトをコピー」
2. カード通知が届く Gmail のアカウントで [Apps Script](https://script.google.com/home/projects/create) を開き、最初の文字を消して貼り付け → 保存
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行ユーザー「自分」、アクセスできるユーザー「全員」→「デプロイ」
4. 「アクセスを承認」→「詳細」→「（安全ではないページ）に移動」→「許可」（自分で作ったスクリプトなので問題ありません）
5. 表示されたウェブアプリの URL をアプリに貼り付けて「接続」→ 過去の利用を確認して取り込み

以降は**アプリを開くたびに新しいカード利用を自動で取り込みます**（30分に1回まで）。スマホでは、パソコンの「📱 スマホでも自動取り込み」の QR コードを読み取るだけで設定できます（自動同期を使っている場合は不要）。

- スクリプトには合言葉が埋め込まれていて、合言葉を知らない人はデータを読めません
- スクリプトは検索条件に合うカード通知メールだけを返し、メールの送信・削除はしません
- カード利用通知の「ご利用内容」（買物・ショッピングなど）も取り込み、明細に表示します
- Amazon・楽天市場などの注文確認メールが同じ Gmail に届いていれば、金額と日付（10日以内）が合うものから買った商品名も付けます（カテゴリも商品名から推定）
- カード会社の会員サイトで「カード利用通知メール」をオンにしておいてください
- Google Cloud の OAuth クライアントIDを使う方法も「Google Cloud で設定」から選べます

## 税金の概算について
- 副業：収入の種類を「副業」にした収入 −「副業の経費」にチェックした支出 ＝ 雑所得
- 競馬：払戻 − 的中馬券の購入額 − 特別控除50万円 ＝ 一時所得（課税対象はその1/2）
- 給与所得者で上記の合計が年20万円以下なら所得税は申告不要として0円（住民税は10%で計算）
- 本業の年収から課税所得を推定し、副業・競馬の所得を上乗せしたときの増加分を計算（所得税は復興特別所得税込み）
- 控除額は2025年分以降の制度をもとにした目安です。正確な税額は税務署・税理士にご確認ください
